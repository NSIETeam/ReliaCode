# 一物一码溯源防串货系统 · 使用手册

> 版本：v2.0 ｜ 运行环境：Windows / Node.js ｜ 端口：3000

---

## 一、系统启动

### 方式一：桌面快捷启动
双击桌面上的 `溯源系统启动.bat`，会自动弹出一个黑色窗口，显示：
```
  正在启动溯源码系统...
  管理后台: http://localhost:3000
  消费者验证: http://localhost:3000/v/溯源码
```
浏览器打开 `http://localhost:3000` 即可进入管理后台。

### 方式二：项目目录启动
双击项目根目录的 `启动系统.bat`，效果一样。

### 方式三：命令行启动
在项目目录下打开终端，执行：
```bash
node server.js
```

### 停止服务
直接关闭黑色窗口，或在终端按 `Ctrl + C`。

**注意：** 启动后请勿关闭黑色窗口，关了服务就停了。首次启动会自动安装依赖（需要联网），之后启动很快。

## 二、管理后台总览

打开 `http://localhost:3000`，进入后台首页。页面能看到：
- 数据统计：产品数、箱码数、子码数、代理商数、已发货箱数、已扫码数、串货预警数
- 最近10条扫码记录
- **工厂装箱入口二维码**（工厂工人扫码进入装箱页面）
- **仓库发货入口二维码**（仓库人员扫码进入发货页面）

后台顶部导航栏：
| 菜单 | 用途 |
|------|------|
| 首页 | 数据总览 + 手机入口二维码 |
| 码生成 | 生成箱码/子码、打印标签（只生码，绑定在工厂装箱做） |
| 工厂装箱 | 工厂扫箱码→输箱规→逐个扫子码自动绑定（防错） |
| 仓库发货 | 扫箱码整箱发货 / 扫子码散件发货 |
| 代理商 | 管理代理商信息 |
| 码查询 | 查所有箱码/子码的状态、归属 |
| 扫码日志 | 所有消费者扫码记录，含串货分级 |
| 品牌营销 | 品牌信息 + 扫码营销活动配置 |

## 三、完整业务流程

### 整体链路

```
品牌方生成箱码+子码
  → 码发给生产工厂
  → 工厂装箱：扫箱码→输箱规→逐个扫子码绑定（防错）
  → 成品入品牌方仓库
  → 仓库发货：选代理商→扫箱码(整箱)或子码(散件)
  → 消费者微信扫码验证（正品/窜货/抽奖）
```

### 第1步：添加产品
进入 **码生成** 页面，在"产品管理"区域：
1. 填写产品名称（必填，如"天山矿泉水500ml"）
2. 填写规格（选填，如"500ml/瓶"）
3. 填写批次号（选填，如"20260815"）
4. 填写箱规（选填，如填8 = 每箱装8个）
5. 点"添加产品"

一个产品只需添加一次，后面可以反复用它生成码。
**箱规说明：** 工厂装箱时系统自动带出产品的默认箱规，工人无需手动输入；装箱页也可以临时修改某一箱的箱规。

### 第2步：添加代理商
进入 **代理商** 页面：
1. 填写代理商名称（必填，如"深圳市 XX 贸易有限公司"）
2. 填写电话（选填）
3. 填写负责区域（重要！如"广东省深圳市"，串货检测靠这个判断）
4. 填写地址（选填）
5. 点"添加代理商"

**区域填写规范：** 建议写"XX省XX市"格式，系统会自动提取省份来判断是跨市（1级窜货）还是跨省（2级窜货）。

### 第3步：生成箱码（父码）
进入 **码生成** 页面，"第一步：生成箱码"区域：
1. 选择产品
2. 填写批次号（选填，不填用产品默认批次）
3. 填写生成数量（1~1000）
4. 点"生成箱码"

生成的每个箱码都是唯一的，以字母 `B` 开头，例如 `BLZK8FG3KP9`。
二维码图片会自动保存到 `public/qr/` 目录下。

### 第4步：生成子码（单品码）
同一个页面，"第二步：生成子码"区域：
1. 选择产品
2. 填写批次号
3. 填写生成数量（1~5000）
4. 点"生成子码"

子码以字母 `S` 开头，例如 `SLZK8FG3KP9`。
此时子码是"未绑定"状态，还没有关联到任何箱码。

### 第5步：打印标签
在码生成页面点"打印标签"按钮，或直接进入 **标签打印** 页面：
1. 选择标签类型：箱码标签 / 子码标签
2. 系统会列出对应的码
3. 勾选要打印的码
4. 点"打印"，弹出A4排版预览页
5. 用浏览器打印（Ctrl+P），选实际打印机打印

标签上印有：品牌名称 + 产品名 + 二维码 + 码值文字。
**建议：** 箱码标签贴在纸箱外面，子码标签贴在单个产品包装上。工厂装箱时扫箱码再扫子码，自动绑定。

### 第6步：工厂装箱（关键环节）
进入 **工厂装箱** 页面（电脑或手机均可）。这是子码绑定到箱码的**唯一环节**，码生成页面只生码不绑定。

页面只有一个扫码框，系统自动识别码的类型，**全程不用点任何按钮**：

1. **扫箱码（B开头）** → 自动开始/切换这一箱，产品默认箱规自动带出
2. **逐个扫子码（S开头）** → 每扫一个自动绑定到当前箱，大进度条实时显示（如 3/8）
3. **扫满自动完成** → 提示"本箱装箱完成"，直接扫下一个箱码开始新箱
4. **防错提示**（扫错会红色警示并计数）：
   - ✗ 本箱已装满还扫 → 提示"本箱已装满（4/4），请扫下一个箱码"
   - ✗ 扫到重复子码 → 提示"该子码已在本箱"
   - ✗ 扫到其他箱的子码 → 提示"已绑定箱码 XXX"
   - ✗ 扫到不同产品的子码 → 提示"产品不符"
   - ✗ 扫到已发货的子码 → 提示"已发货，不能装箱"

页面下方有"本次会话统计"：完成箱数、绑定子码数、扫错次数，方便车间管理。

**扫码枪用法：** 光标保持在输入框，扫码枪连着扫即可（B码/S码自动识别）。
**手机扫码：** 点"手机扫码"按钮调用摄像头。
**补充说明：**
- 如果中途断了，重新扫同一个箱码可以继续装箱（已绑的子码不会丢）
- 箱规可在装箱页临时修改（如这一箱装12个），下一箱扫箱码时恢复产品默认箱规
- 产品没设箱规时，扫箱码后需先在装箱页填一下箱规

### 第7步：仓库发货
进入 **仓库发货** 页面（电脑或手机均可）：

**整箱发货（扫箱码）：**
1. 选择要发给哪个代理商
2. 扫码或输入箱码（以B开头）
3. 填写操作人姓名（选填）
4. 点"发货"
5. 该箱及箱内所有子码状态变为"已发货"，记录代理商和发货时间

**散件发货（扫子码）：**
1. 选择要发给哪个代理商
2. 扫码或输入子码（以S开头）
3. 填写操作人姓名（选填）
4. 点"发货"
5. 该子码单独发货给代理商，不影响同箱其他子码

发货记录表格有"类型"列：绿色标"整箱"，黄色标"散件"，一目了然。

**手机扫码发货：** 页面上有"扫码"按钮，点击调用手机摄像头扫码。仓库人员用手机扫后台首页的"仓库入口二维码"进入发货页即可。

### 第8步：消费者扫码验证
消费者用微信扫描产品上的二维码，会打开验证页面（`/v/码值`），显示：
- 品牌名称、Logo、欢迎语（可在品牌设置里改）
- 产品名称、规格、批次号
- 验证结果：正品已验证 / 未发货 / 尚未出库
- 发货代理商及负责区域
- 扫码次数：第几次扫码
- 首次扫码时间和地点
- 如果有活动且中奖，显示中奖动画和奖品信息
- 如果检测到窜货，显示窜货警告

**扫码次数提醒：**
- 首次扫码：正常显示产品信息
- 多次扫码：页面顶部提示"⚠️ 此码已被扫过X次，首次扫码于 XXXX，请警惕假冒"

## 五、扫码营销活动配置

同一个 **品牌营销** 页面下方，"营销活动"区域：

### 创建活动
1. 填写活动名称（如"开瓶有奖"）
2. 设置开始日期、结束日期
3. 设置中奖率（0~100，比如填10表示10%概率中奖）
4. 选择奖品类型：
   - `红包`：系统随机生成指定金额区间的红包金额
   - `优惠券`：固定金额或奖品名称
   - `谢谢参与`：未中奖的兜底提示
5. 填写奖品名称（如"微信红包"）
6. 填写金额区间（最小~最大，红包类型用）
7. 勾选"启用"
8. 点"创建活动"

### 活动规则
- 只有"已启用"且在有效日期内的活动才会触发
- 只有**首次扫码**的**已发货正品**才参与抽奖
- 同一个码不会重复中奖
- 中奖记录可在页面下方"中奖记录"表格查看

### 启用/停用/删除
- 点"启用/停用"按钮切换活动状态
- 点"删除"移除活动（不影响已有中奖记录）

## 六、窜货检测说明

系统自动检测窜货并分级：
| 级别 | 含义 | 判断逻辑 |
|------|------|----------|
| 0 | 正常 | 扫码地点与代理商负责区域匹配 |
| 1 | 轻度窜货 | 同省不同市 |
| 2 | 重度窜货 | 跨省 |

在 **扫码日志** 页面可看到所有扫码记录，窜货记录有醒目标签（黄色=1级，红色=2级）。

**前提条件：**
- 代理商的"负责区域"必须填写准确（如"广东省深圳市"）
- 消费者扫码时系统会尝试获取其地理位置（目前通过扫码IP粗略判断，正式上线后可接入微信定位或IP定位服务提升精度）

## 八、手机扫码使用方式

系统所有需要扫码的地方都支持两种方式：

### 方式一：手机摄像头扫码（不用扫码枪）
在码输入框旁边有个"扫码"按钮，点击后：
- 调用手机摄像头
- 对准二维码扫描
- 自动填入码值到输入框

适用场景：工厂装箱、仓库发货、码查询、绑定子码。

### 方式二：扫码枪
把光标放在输入框里，用扫码枪扫一下，码值自动输入。系统会自动从完整URL中提取码值（比如扫出 `http://localhost:3000/v/SLZK8FG3KP9`，会自动提取 `SLZK8FG3KP9`）。

### 工人手机入口
后台首页有两个二维码：
- 🔵 **工厂装箱入口** — 工厂工人扫码进入装箱页面
- 🟢 **仓库发货入口** — 仓库人员扫码进入发货页面

工人用微信扫一下对应二维码就能直接打开页面，不需要记住网址。

## 九、给仓库/工厂测试：如何让其他人用上系统

系统目前运行在你的电脑上（localhost:3000），其他人无法直接访问。有三种方式让仓库和工厂测试：

### 方式一：同一WiFi下测试（最快，零成本）

适合：仓库和你在同一个办公室/工厂，连同一个WiFi。

1. 在你的电脑上启动系统（双击桌面 `溯源系统启动.bat`）
2. 查你电脑的局域网IP：
   - 打开命令提示符（Win+R → 输入 cmd → 回车）
   - 输入 `ipconfig` → 回车
   - 找到"IPv4 地址"，类似 `192.168.1.100`
3. 仓库人员手机连上同一个WiFi，用微信或浏览器打开：
   ```
   http://192.168.1.100:3000/warehouse
   ```
   （把192.168.1.100换成你的实际IP）
4. 工厂人员打开：
   ```
   http://192.168.1.100:3000/factory
   ```
5. 消费者测试扫码验证：
   ```
   http://192.168.1.100:3000/v/子码
   ```

**注意：** 必须连同一个WiFi，离开这个网络就访问不了。

### 方式二：用手机热点临时测试

适合：不在同一办公室，但能在同一地点碰头。

1. 你手机开热点
2. 你的电脑连这个热点
3. 仓库人员手机也连这个热点
4. 同方式一，用你电脑热点的IP访问

### 方式三：部署到云服务器（正式给仓库用）

适合：仓库和工厂在不同地点，需要长期使用。

1. 购买云服务器（2核2G+，推荐腾讯云/阿里云，Ubuntu系统，约50~200元/月）
2. 购买域名（30~80元/年，建议和服务器同一家买方便解析）
3. 部署：SSH登录服务器 → 上传代码 → 安装Node.js → `npm install` → 用pm2守护进程
4. 域名解析到服务器IP
5. 配置免费HTTPS（Let's Encrypt）
6. 仓库人员打开 `https://你的域名/warehouse` 即可
7. 工厂人员打开 `https://你的域名/factory` 即可
8. 消费者扫码自动访问 `https://你的域名/v/码值`

**推荐：** 先用方式一或二做内部测试，确认流程没问题后，再买服务器正式部署。

## 十二、常见问题

**Q：启动报错"Cannot find module"？**
A：在项目目录执行 `npm install` 安装依赖后重试。

**Q：二维码图片不显示？**
A：检查 `public/qr/` 目录是否存在且有读写权限，系统会自动往这里写图片。

**Q：扫码提示"溯源码不存在"？**
A：确认扫的是本系统生成的码（B开头是箱码，S开头是子码），不是其他系统的码。

**Q：发货后消费者扫码显示"未发货"？**
A：已修复。系统改为按"是否绑定了代理商"判断发货状态，不会因扫码后状态变化而误判。

**Q：窜货检测不生效？**
A：检查代理商的"负责区域"是否填写了（格式如"广东省深圳市"），以及消费者扫码时是否能获取到位置信息。

**Q：工厂装箱时扫子码提示"产品不符"？**
A：子码和箱码必须属于同一个产品。检查生成码时选择的产品是否一致。

**Q：换了电脑，数据怎么迁移？**
A：把整个项目文件夹拷过去，特别是 `data/traceability.db` 数据库文件和 `public/qr/` 二维码图片。

**Q：二维码是免费无限的吗？**
A：是的，系统用开源 qrcode 库本地生成，不依赖任何第三方服务，完全免费、无限量。

**Q：仓库人员手机打不开页面？**
A：1）确认你的电脑系统正在运行（黑色窗口没关）；2）确认手机和电脑连的是同一个WiFi；3）确认IP地址正确（在电脑上输入 `ipconfig` 查看）；4）Windows防火墙可能拦截了，在"Windows安全中心→防火墙→允许应用"里允许Node.js通过。

## 十三、下一步：部署上线

本系统目前在本机运行，消费者扫码需要公网可访问的地址。上线步骤：
1. 购买云服务器（2核2G+，推荐腾讯云/阿里云，Ubuntu系统，约50~200元/月）
2. 购买域名（30~80元/年，建议和服务器同一家买方便解析）
3. 部署：SSH登录服务器 → 上传代码 → 安装Node.js → `npm install` → 用pm2守护进程
4. 域名解析到服务器IP
5. 配置免费HTTPS（Let's Encrypt）
6. 消费者扫码访问的就是 `https://你的域名/v/码值`

（上线部署可由我远程协助完成）
