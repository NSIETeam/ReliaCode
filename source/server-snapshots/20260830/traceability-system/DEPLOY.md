# 溯源系统部署说明

## 一、买服务器（还没有的话）

推荐**轻量应用服务器**（腾讯云 / 阿里云都有）：

- 配置：2核 2G 内存就够用（系统很轻量）
- 系统：**Ubuntu 22.04**
- 价格参考：几十元/月，新用户常有优惠
- 买完后在控制台找到：**公网 IP** 和设置好的 **root 密码**

> 阿里云叫"轻量应用服务器"，腾讯云也叫"轻量应用服务器"，都行。

## 二、上传部署包

在你自己的电脑上，把 `traceability-system.zip` 上传到服务器。

**方法A：用云控制台的网页终端**（最简单）
1. 服务器控制台里点"远程连接 / 登录"，进入黑窗口
2. 执行：`apt update && apt install -y unzip`
3. 用控制台的"上传文件"按钮（一般工具栏里有）把 zip 传上去（通常传到 /root/ 目录）

**方法B：用命令行 scp**（会命令行的话）
```bash
scp traceability-system.zip root@服务器IP:/root/
```

## 三、一键部署（在服务器上执行）

```bash
cd /root
unzip traceability-system.zip
cd traceability-system
bash setup.sh
```

脚本会自动：装 Node.js → 装依赖 → 用 pm2 守护进程启动 → 设置开机自启。

## 四、放行端口（重要，不做打不开）

去云服务器控制台 → **防火墙 / 安全组** → 添加规则：

- 协议：TCP
- 端口：3000
- 来源：0.0.0.0/0（所有 IP）

## 五、完成

浏览器访问：

| 入口 | 地址 |
|------|------|
| 管理后台 | http://服务器IP:3000/ |
| 码生成 | http://服务器IP:3000/generate |
| 工厂装箱 | http://服务器IP:3000/factory |
| 仓库发货（手机） | http://服务器IP:3000/warehouse |
| 消费者验证页 | http://服务器IP/v/溯源码 |

扫码二维码会自动指向服务器地址（二维码里的链接是按访问地址动态生成的），**部署后重新生成一次二维码**给产品用即可。

## 六、数据说明

- 你的现有数据（4个产品、35个箱码等）已包含在 `data/traceability.db` 里，部署后直接可用
- 以后数据备份：把服务器上的 `data/traceability.db` 下载保存即可（单文件数据库）

## 七、日常运维命令

```bash
pm2 logs trace      # 看日志
pm2 restart trace   # 重启
pm2 stop trace      # 停止
```

## 账号与角色（2026-08-29 更新）

系统已开启登录认证，消费者扫码验证页（/v/码值）保持公开，其余页面和接口均需登录。

| 角色 | 默认账号 | 权限 |
|------|---------|------|
| 总部管理员 | admin / admin123 | 全部功能（码生成、装箱、发货、查询、日志、预警、品牌、账号管理） |
| 工厂装箱 | factory / factory123 | 仅工厂装箱作业 |
| 仓库发货 | warehouse / warehouse123 | 仅扫码发货（操作人自动记录登录账号） |
| 代理商 | 无默认账号，由管理员在"账号管理"创建并绑定 | 仅"我的工作台"（/portal）：查看自己名下库存、发货与扫码数据 |

- **首次登录后请立即修改默认密码**（右上角头像 → 修改密码）
- 管理员在「账号管理」页可新建/停用/重置任意账号密码

## 串货预警

消费者扫码检测到区域不符时自动生成预警（轻度=同省跨市，重度=跨省），
后台导航栏「预警中心」显示未处理数量角标，支持单条或全部标记已处理。

## 自动备份

- 服务器每日 03:00 自动备份 SQLite（保留最近 14 份，存于 data/backups/）
- 品牌营销页底部「数据备份」可立即备份下载、查看和下载历史备份
